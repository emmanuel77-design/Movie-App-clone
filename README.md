# 🎬 Movie App Clone 

A movie discovery application built with Flutter that allows users to search for movies, browse trending titles, and view detailed information about their favorite films. The app integrates with a movie database API to provide real time movie data, including ratings, release dates, genres, and movie overviews.

## ✨ Features

- Search movies by title
- Browse trending and popular movies
- View detailed movie information
- Clean and responsive user interface
- Cross platform support for Android, iOS, Web, Windows, macOS, and Linux
- Real time data from a movie API

## 📱 Screens

- Home Screen
- Search Screen
- Movie Details Screen
- Trending Movies Section
- Popular Movies Section

## 🛠️ Built With

- Flutter
- Dart
- REST API
- HTTP Package
- Provider / Riverpod / Bloc (depending on your implementation)
